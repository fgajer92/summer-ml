# Summer Machine Learning Practice

This repository contains my self-study projects, scripts, and experiments from the summer of 2026. As a technical physics student, my goal was to translate my mathematical background into practical Machine Learning skills, with a strong focus on data analysis and predictive modeling.

## What I've learned and practiced:
* **Data Manipulation:** Data preprocessing, cleaning, and handling datasets using `pandas` and `numpy`.
* **Classical Machine Learning:** Training and evaluating models using `scikit-learn` (Linear/Logistic Regression, Decision Trees, Random Forests).
* **Model Tuning & Evaluation:** Train/test/validation splits, fighting overfitting (regularization, early stopping), and using appropriate metrics.
* **Deep Learning Basics:** Initial theoretical and practical steps into Neural Networks.

This repository serves as my personal sandbox for testing algorithms and understanding the mechanics of ML models, preparing me for more advanced tasks in Time Series analysis and Quantitative Finance.
